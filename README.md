# Catat Belanja 2

App catatan keuangan pribadi: catat dari foto struk, screenshot, atau chat (AI Gemini gratis),
dengan dashboard per periode (tanggal 1 atau tanggal gajian), budget per kategori, kartu kredit,
cicilan, hutang-piutang, laporan akhir periode, dan export Excel/CSV. Data tersimpan di HP.

- Android: APK dibuat otomatis oleh GitHub Actions (tab Actions / Releases).
- iPhone: buka versi web (GitHub Pages) di Safari, lalu Share > Add to Home Screen.

Kode web ada di `app/src/main/assets` (dipakai bersama oleh APK dan versi web).
